Advanced Database Systems Portfolio (MIT 8103)

Student: Cole Folahan Victor
Case study: NaijaMart, a simulated online store based in Lagos selling electronics, fashion, groceries, home and beauty products.
Tools: PostgreSQL on Neon (portfolios 1 to 3 and 5), MongoDB on Atlas (portfolio 4).

 Contents
 
- portfolio-1-database-design: ER diagram, schema, keys, constraints and normalisation
- portfolio-2-query-optimisation: seed data, queries, execution plans and indexes
- portfolio-3-transactions-concurrency: commit, rollback, failed order and a locking test
- portfolio-4-nosql: MongoDB product and order documents, queries and an aggregation
- portfolio-5-distributed-cloud: cloud deployment evidence, a sharding demo and a replication discussion

Each folder has its own README that explains what was done and how it was tested.
